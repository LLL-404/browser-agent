## 📚 文档使用说明

### 1️⃣ [crawler_template.py](crawler_template.py) - 爬虫模板

**适用场景**：
- 电商价格监控
- 商品信息采集  
- 企业数据抓取
- 财经数据获取

**如何使用**：
```python
# 只需修改这几行配置即可！
TARGET_URL = "https://example.com/search?q={keyword}&page={page}"
SEARCH_KEYWORD = "你要采集的关键词"
PAGE_COUNT = 3  # 爬几页

SELECTORS = {
    'item': 'div.product-item',   # 改成目标网站的选择器
    'name': 'h3.title',
    'price': 'span.price',
    'sales': 'span.sales',
}

# 运行后自动保存到 output/ 目录
```

**输出格式**：Excel + CSV + JSON（三格式都有，客户喜欢哪个给哪个）

---

### 2️⃣ [data_processor.py](data_processor.py) - 数据处理模板

**适用场景**：
- 多个Excel/CSV合并去重
- 数据清洗（空值、格式、异常值）
- 批量重命名文件
- 按类型整理文件夹
- 生成分组汇总报表

**使用示例**：
```python
from data_processor import ExcelProcessor, FileAutomationTool, ReportGenerator

# 合并文件
processor = ExcelProcessor('input', 'output')
merged = processor.merge_multiple_files('sales_*.xlsx')

# 清洗数据
clean_data = processor.clean_data(merged)

# 生成报表
ReportGenerator.create_summary_report(clean_data, '产品名称', '价格')

# 文件整理
tool = FileAutomationTool('.')
tool.organize_by_type('messy_folder', 'sorted_files')
```

## 🔥 接单黄金法则

### ✅ 必须做的事：

1. **收定金再开工**（至少30%，理想40%）
2. **分阶段收款**（442模式最佳）
3. **需求文档化**（聊天记录也要截图保存）
4. **按时交付**（延期必须提前沟通）
5. **要好评**（每单必追评，这是你的资产）

### ❌ 绝对不碰：

1. 灰色/黑色产业项目（赌博、破解等）
2. 不收定金的项目（99%会被白嫖）
3. 需求极其模糊的单子（后期无限扯皮）
4. 远低于市场价的单子（浪费你时间）
5. 要求"先做完看效果再说钱"的客户
