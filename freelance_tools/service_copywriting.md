## 五、避坑提醒

### ❌ 绝不接的单子：
1. 涉及破解/逆向/灰色地带的
2. 需求极其模糊说不清的
3. 要求"先做完再说钱"的
4. 明显低于市场价的（如50元做个完整网站）

### ✅ 接单前必问清楚：
- [ ] 具体要什么数据/功能？（列出字段清单）
- [ ] 目标网站/系统是什么？
- [ ] 数据量大概多少？
- [ ] 有没有反爬机制？
- [ ] 什么时候要？
- [ ] 预算大概多少？
- [ ] 付款方式？

### 💰 收款铁律：
1. **必须收定金才开工**（至少30%）
2. **分阶段收款**（442或333模式最佳）
3. **尾款结清再给源码**
4. **所有约定写文字**（聊天记录截图保存）
