# 操作报告：中国化学工程集团招聘岗位爬取

**交付时间**：2026-06-01
**任务**：从国企/央企清单中选择中国化学工程集团，爬取其官方招聘网站的全部在招岗位

---

## 操作步骤

### Step 1：URL 验证
- 目标 URL：`https://cncec.iguopin.com/job`
- 发现该站为 JavaScript 动态渲染（基于国聘平台 iguopin.com），`webfetch` 工具无法直接抓取

### Step 2：浏览器探测
- 使用 Playwright 渲染页面，确认内容结构与 DOM 元素
- 发现页面通过 XHR 调用后端 API 获取岗位数据

### Step 3：API 逆向
- 拦截到 API 端点：`POST https://gp-api.iguopin.com/api/jobs/v1/list`
- 分析请求参数：`page`、`page_size`、`company_id_with_sub`、`nature`（校招/社招编码）
- 关键参数：`company_id_with_sub=10685307085095395`（中国化学工程集团）

### Step 4：全量数据拉取
- 直接调用 API 分页获取：每页 20 条 × 11 页
- 总数据量：**203 条完整岗位记录**
- 每记录含：岗位名称、薪资范围、学历要求、专业要求、职位描述、工作地点、子公司名称、申请截止日期

### Step 5：数据分析
- 按子公司、学历、薪资、地点、岗位类别多维度统计
- 专项标注化工/能源/安全/建筑类岗位
