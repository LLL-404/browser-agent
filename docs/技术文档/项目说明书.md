## 1. 项目背景

### 1.1 业务痛点

在招聘求职、企业信息查询、数据采集等场景中，人工操作浏览器执行重复性任务存在以下痛点：

- **效率低下**：手动在招聘网站逐个搜索、筛选、分析岗位，耗时巨大
- **登录态管理复杂**：多个网站需要频繁登录，Cookie 过期后需要重新认证
- **反爬对抗困难**：BOSS直聘、企查查等平台的反爬虫机制日益严格，普通自动化脚本极易被检测封禁
- **数据整合困难**：采集到的数据分散在不同来源，缺少统一的存储、分析和报告能力
- **AI 集成门槛高**：将浏览器自动化与 AI 编辑器（如 Trae、Cursor）集成，需要实现标准化的 MCP 协议

### 1.2 项目由来

browser-agent 是一个面向 AI 编辑器的浏览器自动化 Agent 框架，提供统一的 **CLI 命令行**、**MCP 协议服务器** 和 **多模式扩展** 能力。项目通过将浏览器控制、反检测、会话管理、数据存储等能力封装为标准化工具，使 AI 能够像人类一样操作浏览器完成复杂的自动化任务。

### 1.3 适用场景

| 场景 | 描述 |
|------|------|
| 智能求职 | BOSS直聘等招聘网站的岗位搜索、筛选、分析、投递状态追踪 |
| 企业信息查询 | 企查查、天眼查等平台的企业信息批量查询与验证 |
| 数据采集 | 任意网页的结构化数据提取与持久化存储 |
| 浏览器自动化测试 | 页面交互、截图、性能分析等自动化测试 |
| AI 对话辅助 | 通过 Chat 引擎注入知识库，进行智能问答 |

## 2. 项目目标与范围

### 2.1 总体目标

构建一个**可扩展、反检测、AI 友好的浏览器自动化框架**，使 AI 编辑器能够通过标准化的 MCP 协议控制浏览器完成复杂任务，同时支持人工通过 CLI 命令行直接操作。

### 2.2 具体目标

| 编号 | 目标 | 衡量指标 |
|------|------|----------|
| O1 | 双引擎浏览器控制 | Camoufox + Playwright 自动回退，启动成功率 ≥ 95% |
| O2 | 反检测能力 | 通过 BOSS直聘、企查查等主流平台的基础反爬检测 |
| O3 | MCP 协议集成 | 提供 30+ 标准化工具，支持 stdio/SSE 双模式 |
| O4 | 多模式扩展 | 即插即用的业务模式架构，支持 CLI 命令和 MCP 工具的动态注册 |
| O5 | 会话持久化 | Cookie + StorageState + localStorage 三种方式，重启自动恢复登录态 |
| O6 | 代码质量保证 | Ruff/MyPy/pytest 零错误，CI/CD 自动化验证 |

### 2.3 范围边界

**在范围内**：
- 浏览器启动、导航、交互、截图、数据提取
- 反检测（指纹伪装、拟人操作、重定向拦截）
- MCP 协议服务器的完整实现
- BOSS直聘适配器（搜索、筛选、分析、报告）
- 会话管理与持久化
- 对话引擎（ChatEngine）

**不在范围内**：
- 手机端浏览器自动化
- 分布式爬虫集群
- 图像识别验证码自动破解
- 付费 API 的代理服务

### 3.2 详细功能列表

#### 3.2.1 浏览器控制引擎

| 功能 | 说明 |
|------|------|
| 双引擎启动 | 优先 Camoufox（C++引擎级反检测），不可用时自动回退 Playwright |
| 页面导航 | 支持 URL 导航、前进/后退、超时控制 |
| 元素交互 | 点击、输入、悬停、选择下拉框、文件上传、键盘按键 |
| 表单填充 | 支持单个和批量填充，自动清空已有内容 |
| 页面状态 | 获取 URL、标题、HTML 源码、纯文本内容 |
| 截图 | 视口截图、全页截图，支持 base64 编码和文件保存 |
| PDF 导出 | 将当前页面保存为 PDF 文件 |
| JS 执行 | 在页面上下文中执行 JavaScript 表达式 |
| 滚动 | 水平和垂直滚动控制 |
| 等待 | 等待元素出现、等待页面导航完成 |
| 对话框处理 | 处理 alert/confirm/prompt 弹窗 |
| 无障碍树 | 获取页面无障碍快照，辅助 AI 理解页面结构 |
| 可交互元素 | 提取所有可交互元素及其唯一 CSS 选择器（@e1 ref 系统） |
| 控制台/网络 | 捕获浏览器控制台消息和网络请求日志 |

#### 3.2.2 反检测系统

| 功能 | 技术方案 |
|------|----------|
| WebDriver 标记隐藏 | 覆盖 `navigator.webdriver` 为 `undefined` |
| 插件伪装 | 伪造 Chrome PDF Viewer、Native Client 等插件 |
| 语言伪装 | 设置 `navigator.languages` 为 `['zh-CN', 'zh', 'en-US', 'en']` |
| Canvas 指纹噪声 | 对 Canvas 像素数据添加微小的随机偏移 |
| WebRTC 防泄漏 | 拦截 RTCPeerConnection，防止真实 IP 泄露 |
| 屏幕分辨率伪装 | 覆盖 `screen` 对象属性 |
| 时区伪装 | 固定为 `Asia/Shanghai` |
| 硬件信息伪装 | 伪造 CPU 核心数、设备内存 |
| 网络信息伪装 | 伪造 `navigator.connection`（4G/10Mbps） |
| Chrome 运行时 | 修复 `chrome.runtime` 对象 |
| 启动参数 | `--disable-blink-features=AutomationControlled` 等 |
| 重定向拦截 | 拦截所有 `about:blank` 和恶意跳转 |
| 拟人操作 | 随机化鼠标轨迹、分段滚动、随机延迟 |
| 浏览器指纹 | 随机化窗口尺寸、User-Agent、操作系统等 |

| 类别 | 工具数 | 工具列表 |

| 页面信息 | 2 | browser_url, browser_scroll |
| 等待 | 2 | browser_wait_navigation, browser_wait_selector |
| 对话框 | 1 | browser_handle_dialog |
| JS 执行 | 1 | browser_evaluate |
| Cookie 管理 | 3 | browser_cookie_list, browser_cookie_get, browser_cookie_set |
| 会话管理 | 2 | browser_storage_state, browser_storage_state_set |
| 存储 | 2 | browser_localstorage_get, browser_localstorage_set |
| 调试 | 2 | browser_console_messages, browser_network_requests |
| 视觉 | 4 | browser_click_coordinate, browser_drag_coordinate, browser_hover_coordinate, browser_screenshot_save |
| PDF | 1 | browser_pdf_save |
| DevTools | 6 | devtools_capture_profiling, devtools_collect_garbage, devtools_enable_device_emulation, devtools_reset_device_emulation, devtools_send_command, devtools_set_location |

#### 3.2.4 BOSS直聘适配器（modes/zhipin）

| 功能 | 说明 |
|------|------|
| 岗位搜索 | 多城市、多关键词搜索，自动翻页采集 |
| 预筛选 | 薪资下限、标题黑名单、公司黑名单、福利标签白名单四规则过滤 |
| 关键词策略 | 按城市搜索结果量自适应选择关键词（L1/L2/L3 三级） |
| 数据存储 | SQLite 持久化存储，支持状态流转（new→analyzed→applied→interview→offer） |
| AI 分析 | 提取待分析职位，供 AI 评估后写回分析结果 |
| 报告生成 | 按评分排序生成推荐报告 |
| 招呼语生成 | 为指定职位生成 Chat 招呼语 Prompt |
| 统计概览 | 按状态、城市、薪资等维度统计求职数据 |
| 导入导出 | 分析结果在数据库和 JSON 文件之间互转 |
| 页面分析 | BOSS 页面类型检测、验证码检测、反爬检测 |

#### 3.2.5 会话管理

| 功能 | 说明 |
|------|------|
| Cookie 持久化 | 保存/加载 Cookie 到 JSON 文件，自动过滤过期 Cookie |
| StorageState | Playwright 兼容的 storage_state 格式，支持 Cookie + origins |
| localStorage | 当前页面的 localStorage 保存与恢复 |
| 登录检测 | 智能轮询检测（URL 变化、Cookie 出现、DOM 变化、登录按钮消失） |
| 会话列表 | 列出所有已保存会话，支持按时间排序 |
| 旧 Profile 清理 | 自动清理超过 7 天的会话 Profile 目录 |

#### 3.2.6 对话引擎（ChatEngine）

| 功能 | 说明 |
|------|------|
| 多 LLM 支持 | DeepSeek、OpenAI、Agnes 等多种 API 提供商 |
| 多轮对话 | 维护对话历史，自动裁剪到最大历史条数 |
| 知识注入 | 动态更新知识库上下文，影响对话质量 |
| 工具调用 | 通过 `/tool <命令>` 标记触发 CLI 命令执行 |
| 重试机制 | 指数退避重试（最多 2 次），网络异常自动恢复 |
| 优雅降级 | API Key 未配置、认证失败、限流、超时等场景均有友好提示 |

## 7. 风险评估与应对策略

### 7.1 技术风险

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| Camoufox 版本兼容性问题 | 中 | 高 | 双引擎回退机制，Camoufox 失败自动降级到 Playwright |
| BOSS直聘反爬升级 | 高 | 中 | 反检测模块独立可插拔，持续更新反检测脚本；Camoufox C++ 引擎级伪装 |
| Playwright API 变更 | 低 | 中 | 通过 agent/ 层封装隔离，仅需修改 browser.py |
| MCP 协议变更 | 低 | 中 | 通过 definitions.py 集中管理工具 schema，变更仅影响一处 |
| 浏览器内存泄漏 | 中 | 低 | 完善的 stop() 资源释放机制，超时强制释放；Profile 目录自动清理 |

### 7.2 项目风险

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| 需求变更频繁 | 中 | 中 | 模式化架构支持即插即用，新需求通过新增模式实现 |
| 第三方服务不稳定 | 中 | 中 | LLM API 支持多 Provider 切换；浏览器操作有完善的超时和重试机制 |
| Cookie 过期导致登录态失效 | 高 | 低 | 智能登录检测和自动提醒；Cookie 过期过滤；会话文件独立管理 |

### 7.3 安全风险

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| API Key 泄露 | 低 | 高 | 支持环境变量引用 `${VAR_NAME}`，不硬编码密钥 |
| Cookie 文件泄露 | 低 | 中 | Cookie 文件已在 .gitignore 中排除；会话目录独立于代码仓库 |
| 浏览器 Profile 泄露 | 低 | 中 | Profile 目录已加入 .gitignore |
