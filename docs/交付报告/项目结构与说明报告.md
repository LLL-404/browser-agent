# 项目结构与说明报告 — browser-agent-framework

**交付时间**：2026-06-03 17:00

## 正文内容

### 项目定位

browser-agent-framework 是一个**通用浏览器自动化 AI Agent 框架**，而非单纯的求职工具。
核心是浏览器控制器 + Agent + CLI + MCP 服务，BOSS 直聘求职只是其 `modes/` 下的一个业务模式扩展。

### 架构层次

```
┌─────────────────────────────────────────────────────────────┐
│                    modes/ (业务模式层)                       │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  modes/zhipin/ — BOSS直聘求职助手                     │   │
│  │  爬虫、搜索策略、筛选、存储、导出                      │   │
│  └──────────────────────────────────────────────────────┘   │
│                  可扩展：其他模式可加入                     │
├─────────────────────────────────────────────────────────────┤
│                    agent/ (核心框架层)                      │
│  ┌────────────┐ ┌──────────┐ ┌─────────────────────────┐   │
│  │ core/      │ │ cli/     │ │ mcp/                    │   │
│  │ 浏览器控制  │ │ CLI入口  │ │ MCP 服务器 (42工具)     │   │
│  │ Agent 管理  │ │ browse  │ │ definitions/handlers    │   │
│  │ 会话管理    │ │ login   │ │ validation              │   │
│  │ 反检测      │ └──────────┘ └─────────────────────────┘   │
│  └────────────┘                                            │
├─────────────────────────────────────────────────────────────┤
│                    shared/ (共享基础设施)                    │
│  配置、异常、日志、性能分析、指纹管理、重试机制               │
├─────────────────────────────────────────────────────────────┤
│                    scripts/ (辅助工具)                       │
│  浏览器管理/登录态/调试/报告/开发工具                         │
└─────────────────────────────────────────────────────────────┘
```

### 目录说明

| 路径 | 分类 | 说明 |
|------|------|------|
| `src/agent/core/` | 核心 | 浏览器控制器(`browser.py`)、Agent(`agent.py`)、会话(`session.py`)、页面(`page.py`)、反检测(`anti_detect.py`)、能力开关(`capabilities.py`)、配置加载(`mcp_config.py`) |
| `src/agent/cli/` | 核心 | CLI 入口 `main.py` — `browse` / `login` 子命令 |
| `src/agent/mcp/` | 核心 | MCP 协议服务器 — 42 个工具定义(`definitions.py`)、处理器(`handlers.py`)、服务生命周期(`server.py`)、参数验证(`validation.py`) |
| `src/modes/zhipin/` | 模式 | BOSS直聘求职模式 — 爬虫(`scraper.py`)、搜索策略(`keyword_strategy.py`)、筛选(`pre_filter.py`)、存储(`storage.py`)、导出(`exporter.py`)、选择器(`selectors.py`)、页面分析(`page_analyzer.py`) |
| `src/shared/` | 基础设施 | 配置(`config.py`)、异常(`exceptions.py`)、错误处理(`error_handler.py`)、日志(`logging_config.py`)、profiler(`profiler.py`)、指纹管理(`fingerprint_manager.py`)、重试(`retry.py`)、延迟(`delay.py`) |
| `src/scripts/` | 工具 | 浏览器管理(`browser/`)、登录态(`login/`)、调试(`dev/`)、报告(`report/`)、文档(`docs/`) |
| `src/tests/` | 测试 | 11 个测试文件 + 2 个子目录 |
